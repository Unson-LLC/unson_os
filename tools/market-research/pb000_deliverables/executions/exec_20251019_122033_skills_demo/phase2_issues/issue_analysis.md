## 課題の4層階層分析

### 【表面的課題】Surface Level
1. **Excel手作業でのデータ集計に時間がかかる**
   - 現状: 統計分析を手動で実施
   - 時間損失: 週5-10時間程度と推測

2. **基本的なプログラミングスキルしかない**
   - 現状: PLCの基本操作、高度な開発経験なし
   - 限界: 効率化ツール自作が困難

3. **SNS投稿が趣味偏重で専門性を発信できていない**
   - 現状: 製造業・研究開発の専門性がInstagramに反映されていない
   - 機会損失: 業界ネットワーク構築の機会を逃している

### 【機能的課題】Functional Level
1. **データ分析スキルの欠如による業務効率低下**
   - Why: Excel手作業 → 時間がかかる → 分析精度が低い
   - 影響: 品質改善提案のスピードが遅い

2. **キャリアアップに必要なリーダーシップ経験の不足**
   - Why: 現場とマネジメントの中間ポジション → 明確な権限なし → リーダーシップ発揮機会が限定的
   - 影響: 部門マネジメント目標達成が困難

3. **業界特化スキルによる転職市場での弱さ**
   - Why: 製造ライン・材料研究特化 → 汎用性低い → 他業界へ移れない
   - 影響: キャリアの選択肢が限定される

### 【感情的課題】Emotional Level
1. **「組織貢献」への強い使命感からくる自己犠牲**
   - Why: 「組織の持続的成長に寄与したい」という動機 → 自己のキャリア発展より組織優先 → 自己実現の遅れ
   - 心理的負荷: 中〜高

2. **マネジメント志向と技術的限界のギャップによる焦燥感**
   - Why: 部門マネジメントを目指す → 現状の技術スキルでは不十分 → 目標達成への不安
   - 心理的負荷: 高

3. **SNSで専門性を発信できない疎外感**
   - Why: 趣味投稿のみ → 業界での存在感ゼロ → プロフェッショナルアイデンティティの欠如
   - 心理的負荷: 低〜中

### 【根本的課題】Fundamental Level
1. **「ITエンジニア」という職種定義の曖昧性**
   - Why: 統計上はIT業界だが、実際は製造・研究業務 → 適切なキャリアパス・スキル開発情報が見つからない
   - 構造的問題: IT業界の多様性が職種分類・教育システムに反映されていない

2. **中堅・中小企業における人材育成リソース不足**
   - Why: 大手IT企業のような体系的研修がない → 個人の自己学習頼み → スキル格差拡大
   - 構造的問題: 企業規模による教育投資の不均衡

3. **現場実務者とマネジメント層の断絶**
   - Why: 製造現場/研究室 ⇔ 経営層の間にキャリアパスが不明瞭 → ロールモデル不在 → キャリア形成の不透明性

### 課題: 「Excel手作業でのデータ集計」

### 課題: 「マネジメント志向と技術限界のギャップ」
