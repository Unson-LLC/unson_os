# EventSync Pro Landing Page

EventSync Proのランディングページです。LP Template Generatorから生成されました。

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3001 を開いてください。

## カスタマイズ

`lp-config.json`を編集してLPの内容をカスタマイズできます。

## ビルド・デプロイ

### 開発サーバー
```bash
npm run dev
```

### プロダクションビルド
```bash
npm run build
npm start
```

### 静的エクスポート
```bash
npm run export
```
